# GifsApp

GifsApp es una aplicación web simple que permite buscar GIFs animados de manera rápida y sencilla.

## Características

- Buscar GIFs por palabra clave.
- Descargar GIFs directamente a tu dispositivo.
- Copiar GIFs al portapapeles para usarlos fácilmente en chats, redes sociales u otras aplicaciones.

## Tecnologías usadas

- React
- Tailwind CSS
- Vite

## Cómo usarla

1. Escribe una palabra clave en el buscador.
2. Explora los GIFs mostrados.
3. Descarga o copia el GIF que te guste con un solo clic.

---

Proyecto ideal para aprender a trabajar con APIs y React de forma práctica.
